# CoronaBoard

Epitech YEP project (April 2020): proofs of concept for a COVID-19 dashboard in Vue.js.

| Folder | What it is |
| --- | --- |
| `POC_Map` | World map (Leaflet) with per-country case circles |
| `POC_VueJs` | Vue.js app skeleton |
| `chart-js-demo` | Case charts with Chart.js / vue-chartjs |

## Run a POC

```bash
cd POC_Map        # or POC_VueJs, chart-js-demo
npm install
npm run dev       # chart-js-demo: npm run serve
```
